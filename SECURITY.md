# Security Policy

## Supported Versions

The following versions of AUREON OS currently receive security updates.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ Yes     |
| < 1.0   | ❌ No      |

As new major versions are released, this table will be updated accordingly.

---

## Reporting a Security Vulnerability

The security of AUREON OS is important. If you discover a security vulnerability, please report it responsibly.

### Please Do Not

* Do **not** disclose the vulnerability publicly before it has been investigated.
* Do **not** create a public GitHub issue for sensitive security vulnerabilities.
* Do **not** exploit vulnerabilities beyond what is necessary to demonstrate the issue.

### Please Include

When reporting a vulnerability, provide as much information as possible:

* A clear description of the issue
* Steps to reproduce the vulnerability
* Affected version(s)
* Expected behavior
* Actual behavior
* Logs, screenshots, or proof of concept (if applicable)
* Potential impact

Reports that include clear reproduction steps help us investigate and resolve issues more quickly.

---

## Reporting Method

Please report security vulnerabilities through one of the following methods:

* **GitHub Private Vulnerability Reporting** (preferred, if enabled for this repository)
* Contact the project maintainer directly through the contact information listed in the repository profile

Do not report sensitive vulnerabilities through public issues.

---

## Response Process

After receiving a valid report, we aim to:

* Acknowledge receipt as soon as practical
* Investigate the reported issue
* Determine the severity and impact
* Develop and test a fix
* Release a security update when appropriate
* Publicly disclose the issue after a fix is available, when appropriate

Response times may vary depending on the complexity of the issue.

---

## Scope

This policy applies to:

* AUREON OS
* Build scripts
* Packaging
* Live-build configuration
* Installer configuration
* Official project assets contained in this repository

Third-party software included with AUREON OS is maintained by its respective upstream projects. Security issues affecting those components should also be reported to their maintainers when appropriate.

---

## Responsible Disclosure

We appreciate security researchers who act responsibly and work with us to improve the security of AUREON OS. Coordinated vulnerability disclosure helps protect users while allowing sufficient time to develop and distribute fixes.

Thank you for helping keep AUREON OS secure.
