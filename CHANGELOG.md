# Changelog

All notable changes to **AUREON OS** will be documented in this file.

The format is based on **Keep a Changelog**, and this project follows **Semantic Versioning** where practical.

---

## [1.0.0] - Initial Release

### Added

* First public release of AUREON OS.
* Debian Testing based system.
* GNOME desktop environment.
* Calamares graphical installer.
* UEFI and Legacy BIOS boot support.
* Custom AUREON branding.
* Custom wallpapers, icons, and themes.
* Preconfigured GNOME desktop.
* Essential productivity applications.
* Security and networking tools.
* Firefox web browser.
* Fastfetch system information utility.
* Git support.

### Changed

* Replaced Debian branding with AUREON branding.
* Customized boot menu and splash screen.
* Optimized default GNOME settings.
* Improved system appearance and usability.

### Fixed

* Various live-build configuration issues.
* Bootloader compatibility improvements.
* Package dependency fixes.
* Installer configuration improvements.

### Known Issues

* Some GNOME extensions may require updates after major GNOME releases.
* Hardware support depends on the Debian Testing kernel and firmware available at build time.
