# Contributing to AUREON OS

Thank you for your interest in contributing to **AUREON OS**! Every contribution helps improve the project.

## Ways to Contribute

You can contribute by:

* Reporting bugs
* Suggesting new features
* Improving documentation
* Fixing bugs
* Submitting code improvements
* Testing development builds
* Improving translations
* Creating themes, icons, or wallpapers

## Before You Start

Before creating an issue or pull request:

* Search existing issues to avoid duplicates.
* Read the project documentation.
* Use the latest development version whenever possible.

## Reporting Bugs

When reporting a bug, please include:

* A clear description of the problem
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Screenshots (if applicable)
* Hardware specifications
* AUREON OS version
* Relevant logs or error messages

## Suggesting Features

Feature requests should include:

* A clear description of the idea
* Why the feature would be useful
* Possible implementation details (optional)

## Development Guidelines

* Write clean and readable code.
* Follow existing project structure and naming conventions.
* Test your changes before submitting.
* Keep commits focused on a single change.
* Update documentation when necessary.

## Commit Messages

Use descriptive commit messages, for example:

* `feat: add new GNOME extension`
* `fix: resolve boot menu issue`
* `docs: update installation guide`
* `refactor: simplify build script`

## Pull Requests

Before opening a pull request:

* Ensure the project builds successfully.
* Test your changes.
* Update documentation if needed.
* Keep pull requests focused on one feature or fix.
* Link related issues when applicable.

## Code Style

* Use meaningful variable and function names.
* Keep scripts well documented.
* Remove unused code before submitting.
* Follow shell scripting best practices.

## Documentation

Documentation improvements are always welcome.

Examples include:

* Fixing spelling or grammar
* Adding tutorials
* Improving setup instructions
* Explaining build processes
* Adding screenshots

## Community Guidelines

Please:

* Be respectful and constructive.
* Welcome new contributors.
* Give helpful feedback.
* Focus on solving problems together.

## License

By contributing to AUREON OS, you agree that your contributions will be licensed under the same license as the project.

Thank you for helping make **AUREON OS** better!
